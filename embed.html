Adding a licence to the snippet

The configurator above never asks for your white-label key, because a key does not belong in a shared preview. If you are on the plan, paste the snippet as usual and then add two attributes to it by hand:

data-wl="your-licence-key"
data-logo="https://your-site.example/logo.png"

The widget asks helpmebreath.com once per visit whether that key is live and whether it covers the domain the widget is sitting on. Only then does the attribution line come off and your logo go on. If the answer does not come back — the network is down, the licence has lapsed, the domain is not on it — the free widget renders with attribution rather than something half-branded. The key travels inside your page's HTML, so treat it as public, and that is exactly why the domain list matters: a licence with no domains on it cannot white-label anything at all, so a key lifted from your page's source is useless on a site you did not list. List your domains when you activate the key on the plan page — there is a field under the licence box for them.

data-brand="Your practice name" is free and needs no key. It prints a line of text above the timer; it does not remove the attribution.

Installing it on the common platforms

Anywhere you can paste raw HTML, the snippet works unchanged. These are the paths through the editors people actually use.

WordPress
In the block editor, add a Custom HTML block and paste the snippet into it. Preview the block before publishing — some security plugins strip script tags from posts, and if yours does you will see an empty block. In the classic editor, switch to the Text tab first. On WordPress.com, custom HTML with scripts needs a Business plan or higher.
Squarespace
Add a Code block where you want the timer and paste the snippet. Leave the block's mode set to HTML and turn Display Source off. Squarespace does not render code blocks in the editor preview, so save and view the live page to see the timer.
Wix
Use Add → Embed Code → Embed HTML, choose the Code option and paste the snippet. Wix puts your code inside its own iframe with a fixed size, so give that Wix element a height of roughly 480 pixels; the automatic resizing described below cannot reach through Wix's wrapper.
Webflow
Drag an Embed element onto the canvas and paste the snippet into the code editor. The Designer shows a placeholder rather than the live widget; publish to a staging domain to check it. Webflow's free Starter plan does not include custom code, so this needs a paid site plan.
Notion
Not supported. Notion pages cannot run scripts and its /embed block only accepts a URL, not HTML. You can paste a link to a timer page instead, which will render as a bookmark card, but the timer will not run inside Notion. The same limit applies to most read-only note tools.

How it behaves once it is on your page

The snippet is a script tag that immediately replaces itself with an iframe. That is the whole trick, and it has a few consequences worth knowing.

It makes no third-party requests. Inside the frame there is one stylesheet and the timer code, both from helpmebreath.com, and nothing else. No analytics, no advertising library, no web font, no cookie. The widget stores your visitor's sound preference in browser storage that modern browsers partition to your site, and that value never leaves the device. If your privacy notice lists embedded third parties, the honest entry is that a breathing timer is loaded from helpmebreath.com and sets no cookies. There is exactly one exception, and it is one you would have to switch on yourself: a white-label key with a data-logo attribute fetches that image from the address you gave, once the key has been verified.

It sizes itself. The frame measures its own content and posts the height to your page; the loader listens for that message and adjusts the iframe. The message is only accepted from the helpmebreath.com origin, so nothing else on the internet can resize your iframe. Kiosk mode is the exception: it fills whatever box you give it, so set the height yourself there.

It is keyboard and screen-reader operable. Space starts and pauses, S stops, and every phase change is announced through an ARIA live region rather than spoken audio, so it does not talk over a class or a screen reader. If a visitor has asked their system for reduced motion, the circle holds one size and a ring drawn around its edge carries the pace instead.

It fails quietly. Everything in the loader sits inside one try/catch. An old browser, a blocked request or a content blocker leaves your page as it was.

Common questions

Is the embedded breathing timer really free?

Yes. All seven patterns, every session length, audio and vibration cues, kiosk mode and unlimited page views are free, with no account and no API key. The free widget carries a small "Powered by Help Me Breathe" line under the timer. The paid plan removes that line and adds your own logo, but nothing about the timer itself is held back.

Does the widget track my visitors?

No. The frame loads one stylesheet and the timer code from helpmebreath.com and nothing else. There is no analytics script, no advertising library, no web font and no cookie inside it. Session settings are stored in the browser's own storage, partitioned to your site, and never sent anywhere.

Will it slow my page down?

The loader is about 3 KB and the iframe is marked loading="lazy", so nothing downloads until the widget is close to the viewport. Because it lives in an iframe it cannot block your page's rendering, and its styles cannot leak into yours.

Can I put the widget on more than one page or more than one site?

The free widget can go on as many pages and as many sites as you like, including several embeds on the same page. A white-label key is bound to the sites you list when you set it up, so list every site you want your own logo to appear on.

How do I change the height of the widget?

You do not have to. The frame measures itself and posts its height to your page, and the loader resizes the iframe to match. If you would rather fix the height yourself, style the iframe with CSS after it has been inserted; the loader only sets a height when it receives a measurement.

What happens if helpmebreath.com is unreachable?

The loader fails silently. It is wrapped in a single try/catch, so a blocked or slow request leaves your page exactly as it was, with no error and no empty box beyond the iframe's reserved space.

A note on what this is

A breathing timer is a paced-breathing tool, not medical care, and putting one on your site does not make it one. Nothing here treats, cures or replaces treatment for any condition.
